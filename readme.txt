== Description ==

= Heretek Analytics =

Heretek Analytics is an open-source, telemetry-free fork and overhaul of Google Analytics for WordPress, forged under the GNU General Public License v3.0 (GPLv3).

While commercial distributions lock eCommerce metrics, form conversions, custom dimensions, PPC tracking, and raw reporting data behind expensive annual paywalls (up to $799/yr), Heretek Analytics provides permanent, unrestricted access to all Pro and Agency tier reporting modules.

= Unlocked Capabilities =

* **Core GA4 Tracking**: Accurate tracking via gtag.js with automatic measurement protocol handling.
* **Augur Reports Dashboard**: Interactive Vue 3 reports for Audience, Publishers, eCommerce, Forms, PPC, and Media.
* **Enhanced eCommerce**: Complete funnel attribution for WooCommerce and Easy Digital Downloads (impressions, product clicks, cart additions, checkouts, transactions, and refund tracking).
* **Automated Form Attribution**: Track impression and conversion metrics across WPForms, Gravity Forms, Contact Form 7, Ninja Forms, Fluent Forms, and generic HTML forms.
* **Custom Dimensions**: Track author, post type, category, tags, logged-in status, user ID, SEO score, focus keywords, and publication date.
* **PPC & Ad Tracking**: Google Ads conversion tracking and Meta Pixel event integration.
* **Media Tracking**: Automated playback, progress, and completion tracking for YouTube, Vimeo, and native HTML5 videos.
* **EU Consent Mode v2**: Full support for Google Consent Mode v2 and automated PII anonymization.
* **Autonomous Local REST Gateway**: Dashboard queries execute against your local WordPress REST API and Google's GA4 Data API, eliminating third-party cloud proxy relays.
* **Blood & Steel Interface**: Immersive cyber-theurgy dark aesthetic with Obsidian surfaces, Cinzel typography, and glowing telemetry indicators.
* **Native GitHub Releases Updater**: In-dashboard one-click updates directly from the official Heretek-AI GitHub repository.
* **Zero Telemetry**: Completely devoid of phone-home beacons, tracking scripts, and unsolicited upsell notifications.

== Installation ==

1. Download the latest `heretek-analytics.zip` release from https://github.com/Heretek-AI/Heretek-Analytics/releases
2. In your WordPress admin, go to **Plugins** > **Add New** > **Upload Plugin**.
3. Select `heretek-analytics.zip` and click **Install Now**.
4. Activate the plugin.
5. In your admin sidebar, navigate to **Heretek Analytics** > **Settings** to add your GA4 Measurement ID (`G-XXXXXXXXXX`).

== Frequently Asked Questions ==

= Do I need a license key? =
No. Heretek Analytics is 100% free software licensed under GPLv3. All Pro and Agency capabilities are permanently unlocked.

= Does this plugin send data to third-party servers? =
No. Telemetry pings, Customer360 trackers, and remote promotional feeds have been permanently removed. Tracking data travels strictly between your site, your visitors' browsers, and Google Analytics.

= How do updates work? =
Heretek Analytics includes an integrated GitHub Releases updater. When a new version is tagged on GitHub (`Heretek-AI/Heretek-Analytics`), your WordPress admin will notify you under **Dashboard** > **Updates** and allow one-click in-place upgrading.
